Lab 8: Evolution problems with finite elements

In this lab the finite element machinery of Lab 7 is combined with the Crank–Nicolson time integrator to evolve parabolic and Schrödinger-type equations on two-dimensional domains. The system matrix is assembled once, and each time step is a linear solve.

Notebooks

  • QM.ipynb (download · view): the free Schrödinger equation iut=Δui u_t = \Delta uiut​=Δu on the unit square with homogeneous Dirichlet conditions, using complex finite elements. Crank–Nicolson is unitary here, so the L2L^2L2 norm is conserved; the notebook monitors it, checks convergence against an exact eigenmode and evolves wave packets. Note the sign convention: with iut=Δui u_t = \Delta uiut​=Δu, packets move in the direction opposite to their wave vector.

  • Double_Slit.ipynb (download · view): the same solver applied to a wave packet hitting a double slit, on an unstructured mesh, with an optional absorbing layer near the boundary.

  • Heat.ipynb (download · view): the heat equation ut=Δuu_t = \Delta uut​=Δu with the same method. It includes a test against an exact decaying mode.

The notebooks need Gridap, GridapGmsh, GridapMakie, GLMakie and FileIO. The results are written as .vtu files in a Results/ folder, to be visualized with VisIt or Paraview.

Meshes for the double slit, to be placed in a models/ folder next to the notebook: doubleslitjunta_dis.msh (the one used by the notebook), double_slit.msh, doubleslitjunta.msh, doubleslitgrosa.msh.
